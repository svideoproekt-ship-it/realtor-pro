# 🏠 RealtorPro — Программа для риэлторов

Современное веб-приложение для управления объявлениями о недвижимости с возможностью публикации на доски объявлений и в Telegram каналы.

## ✨ Возможности

- 📊 **Дашборд** — статистика объявлений, просмотров и обращений
- 📋 **Объявления** — управление объектами недвижимости (продажа/аренда)
- ✏️ **Создание** — мастер создания объявлений с выбором площадок
- 📡 **Площадки** — управление каналами публикации (Авито, ЦИАН, Telegram)
- ⚙️ **Настройки** — профиль, уведомления, API ключи
- 🌙 **Тёмная тема** — стильный интерфейс с градиентами
- 📱 **Адаптивность** — работает на десктопе и мобильных устройствах

## 🛠 Технологии

- **React 18** + **TypeScript**
- **Vite** — быстрая сборка
- **Tailwind CSS** — стилизация
- **Lucide React** — иконки
